Background

왜 StudyBalance가 필요할까요?

기존 학습 플랫폼이 놓치고 있던 문제들을 살펴봅니다.

Problem 01

집중력 저하와 피로 누적

현대의 학생과 직장인은 장시간 학습·업무로 인해 집중력이 저하되고 피로가 쌓이는 경우가 많습니다.

Problem 02

비체계적인 시간 관리

학습 시간과 휴식 시간을 체계적으로 관리하지 못해 전체적인 학습 효율이 떨어지는 문제가 발생합니다.

Problem 03

기존 플랫폼의 한계

공부 기능에만 집중하거나 휴식 기능만 제공하여, 학습과 휴식을 통합적으로 관리하기 어렵습니다.

본 프로젝트는 AI 기반 학습 관리와 휴식 시스템을 결합한 웹 플랫폼을 개발하여 사용자가 효율적인 학습 습관을 형성하고, 집중력과 생산성을 향상시킬 수 있도록 지원하는 것을 목표로 합니다.

Features

주요 기능

카드를 클릭하면 각 기능의 세부 내용을 확인할 수 있습니다.

① ACCOUNT

회원가입 및 로그인

간편하고 안전한 계정 관리
  • 이메일 회원가입 및 로그인
  • Google 소셜 로그인
  • 비밀번호 찾기
  • 프로필 관리
  • 학습 목표 및 관심 분야 설정
② TIMER

스마트 공부 타이머 (포모도로)

원하는 공부·휴식 시간으로 몰입도를 높입니다
  • 공부 시작 / 종료
  • 일시정지 및 재시작
  • 공부 시간 직접 설정
  • 포모도로 모드 (25분 공부 / 5분 휴식)
  • 장시간 학습 모드 (50분 공부 / 10분 휴식)
  • 자동 휴식 전환
  • 하루 목표 공부시간 & 현재 진행률 표시
  • 오늘 누적 공부시간 제공
③ PLANNER

학습 플래너

시험일까지 AI가 학습 일정을 설계합니다
  • 시험일까지 학습 일정 생성
  • 과목별 학습 비중 자동 조정
  • 부족한 과목 우선 추천
  • 하루 학습량 자동 분배
  • 목표 달성률 예측
입력 · 시험까지 20일 / 영어, 수학, 자료구조 ↓ AI 추천 월요일: 영어 2시간 · 화요일: 수학 3시간 · 수요일: 자료구조 2시간
④ TO-DO

오늘의 목표 (To-Do)

하루 학습 목표를 세우고 완료 여부를 관리
  • 할 일 추가
  • 완료 체크
  • 우선순위 설정
  • 목표 달성률 표시
  • 미완료 항목 자동 이월
⑤ DASHBOARD

학습 분석 대시보드

단순 시간이 아닌 학습 데이터를 분석합니다
  • 공부 시간 / 휴식 시간 통계
  • 과목별 공부 시간
  • 집중 만족도 기록 (1~5점)
  • 주간 · 월간 그래프
  • 목표 달성률 분석
AI 분석 제공 · 가장 집중이 잘 되는 시간 · 가장 공부가 부족한 과목 · 평균 공부시간 · 추천 공부시간
⑥ REST MODE

스마트 휴식 모드

공부 종료 후 자동 실행되는 회복 루틴
  • 타이머 종료 시 자동 실행
  • 스트레칭 가이드 · 눈 운동 · 심호흡 가이드
  • 명상 음악 · 백색소음 · 자연의 소리

단순 음악 재생이 아닌, 휴식 체크리스트로 실제 휴식을 유도합니다.

⑦ FOCUS ENV

집중 환경 설정

방해 요소를 최소화하는 나만의 학습 환경
  • 집중 음악 선택
  • 백색소음 선택
  • 다크모드
  • 전체화면 공부모드
  • 알림 최소화
⑧ CALENDAR

학습 캘린더

학습 기록을 날짜별로 한눈에
  • 공부시간 자동 저장
  • 목표 달성 여부 표시
  • 공부 일수 (Streak) 확인
  • 월별 통계
⑨ JOURNAL

공부 일기 및 회고

하루를 기록하고 스스로 되돌아보기
  • 오늘 공부한 내용 기록
  • 어려웠던 부분 기록
  • 내일 목표 작성
  • AI 피드백 제공
⑩ REPORT

학습 리포트

주간 · 월간 학습 결과를 자동 분석
  • 총 공부시간
  • 목표 달성률
  • 가장 많이 공부한 과목
  • 부족한 과목 분석
  • 다음 주 추천 계획
